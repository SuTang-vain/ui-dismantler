# 明星组合 · 动态百科成员探索卡 - 设计规范

> 源自 `BLACKPINK v10` 案例页（PC 788×492 / WISE 380×456 / 极端小屏 280×340），用于"明星组合"垂类的统一组件库建设。

## 一、主题色系统

### 1.1 设计令牌（CSS Custom Properties）

所有颜色均通过 `:root` / `.sg-frame` 变量定义，便于主题切换与复用。原案例变量归一化到 `--sg-*` 命名空间：

| 原变量 | 归一化 | 值 | 语义 / 用途 |
|---|---|---|---|
| `--ink` | `--sg-ink` | `#1E1F24` | 主文字 / 头像兜底深色背景 |
| `--muted` | `--sg-muted` | `#848691` | 次级文字（副标题、说明、故事正文） |
| `--subtle` | `--sg-subtle` | `#B7B9C1` | 三级文字（占位、计数 `<small>`、引导提示） |
| `--note` | `--sg-note` | `#90929a` | 声明/来源说明文字（介于 muted 与 subtle） |
| `--line` | `--sg-line` | `#ECEDF1` | 分割线 / 卡片描边 / 未激活指示点 |
| `--paper` | `--sg-paper` | `#FFFFFF` | 卡片底色 / 主面板背景 / 故事面板底 |
| `--stage` | `--sg-stage` | `#F8F8F8` | 画布舞台背景（body） |
| `--primary` | `--sg-primary` | `#6487FA` | **品牌主色** - 选中描边、激活态、主按钮、箭头、时间轴节点、kicker |
| `--accent` | `--sg-accent` | `#E94F76` | **强调色** - "其它"Tab、创作故事引导点、年份高亮、故事关闭 hover |
| `--accent-2` | `--sg-accent-2` | `#111111` | 备用深色强调（预留） |
| `--soft` | `--sg-soft` | `#F2F4FB` | 主色浅底 - 选中卡片背景、hover 背景、展开态时间线节点 |
| `--soft-pink` | `--sg-soft-accent` | `#FFF0F4` | 强调色浅底（预留） |
| — | `--sg-white` | `#FFFFFF` | 纯白（箭头 hover 反白、激活圆点） |
| — | `--sg-neutral-soft` | `#FAFAFB` | 中性浅底（时间线轨道、卡片底纹） |
| — | `--sg-ink-soft` | `#2A2B33` | 头像兜底渐变起点（比 ink 略浅） |
| — | `--sg-panel-top` | `#FBFBFD` | 详情面板渐变顶 |
| — | `--sg-panel-bottom` | `#F5F7FC` | 详情面板渐变底 |

### 1.2 语义分组

- **文字层级**：`--ink` > `--muted` > `--note` > `--subtle`（四级灰阶）
- **品牌双色调**：`--primary`（蓝紫，主功能色）+ `--accent`（粉红，"其它/故事"语义色）
- **选中态**：边框 `--primary` + 背景 `--soft`（蓝紫浅底组合）
- **强调态**：圆点 `--accent` + 文字 `--accent`

### 1.3 渐变与叠加

| 用途 | 值 |
|---|---|
| 详情面板底色 | `linear-gradient(180deg, var(--sg-panel-top) 0%, var(--sg-panel-bottom) 100%)` |
| 成员卡底部信息蒙版 | `linear-gradient(to top, rgba(0,0,0,0.75), transparent)` |
| 作品卡底部信息浮层 | `linear-gradient(transparent, rgba(0,0,0,0.82))` |
| 头像兜底渐变 | `linear-gradient(135deg, var(--sg-ink-soft) 0%, var(--sg-ink) 100%)` |
| Modal 遮罩 | `rgba(30, 31, 36, 0.45)` |

> 渐变中的 `#FBFBFD`/`#F5F7FC`/`#2A2B33` 等为纯黑白灰蒙版衍生色，按 spec 允许保留；其余颜色一律走 `var(--sg-*)`。

## 三、Tab 元素

### 3.1 结构

顶部 4 等分 Tab Bar，使用 `grid-template-columns: repeat(4, 1fr)`：

```
[ 成员详情 <small>4</small> ] [ 经历 <small>6</small> ] [ 团体作品 <small>6</small> ] [ 其它 ↗ ]
```

- **前 3 个 Tab**：切换面板，激活时 `border-bottom: 2px solid var(--sg-primary)`，文字由 `--muted` -> `--ink`
- **第 4 个 "其它" Tab**（`.sg-tab-more`）：不切换面板，打开 Modal；激活态使用 `--sg-accent` 下划线，未激活时尾部显示 `↗` 图标（CSS `::after`）

### 3.2 Tab 属性约定

- `role="tab"` / `aria-selected` / `aria-controls`
- "其它" Tab 额外维护 `aria-expanded`（Modal 开关同步）
- 计数 `<small>` 显示成员/经历/作品数量，激活时颜色由 `--subtle` 升为 `--muted`
- 切换面板时：同步 `aria-selected`、`hidden`、`.active` 类

### 3.3 尺寸

| 场景 | 高度 | 字号 | 内边距 |
|---|---|---|---|
| PC | 36px | 12.5px / 600 | `0 18px` |
| WISE ≤500px | 32px | 11.5px | `0 14px` |
| 极端 ≤320px | 36px | 10px | `0 8px`（`<small>` 隐藏） |

## 四、交互模式

### 4.1 视图栈（View Stack）

`.sg-view-stack` 内多个 `.sg-view` 绝对定位堆叠（`position:absolute; inset:0`），仅 `.active` 显示（`display: grid`）。Tab 切换通过显隐完成，无路由。

### 4.2 成员视图（Members）

- **2×2 网格**展示成员头像卡，每页 4 人
- **点击成员卡**：切换右侧"详情面板"内容（成员↔团体关系）；小屏（≤500 或 ≤380h）弹出成员 Modal（含头像信息头 + 关系列表）
- **自动播放**：3 秒/个循环切换选中成员，任意用户交互（click/touchstart）后停止
- **轮播控件**：左右圆形箭头（`--primary` 填充、hover 反白）、底部圆点指示器（激活态拉长为胶囊）
- **头像容错**：`load` 加 `.is-loaded`、`error` 加 `.is-error`；兜底显示 `avatar-fallback`（首字母 + 深色渐变）

### 4.3 经历视图（Timeline）- 原地展开故事

v10 的核心特性：**所有屏幕尺寸下，点击时间线条目原地展开经历背景故事**，不弹 Modal。

- **横向滚动轨道**（`scroll-snap-type: x mandatory`），PC 每页 3 条 / 小屏 2 条
- **PC 端**：箭头绝对定位在轨道左右两侧（`.sg-tl-prev-pc` / `.sg-tl-next-pc`）
- **移动端**：底部控制栏（左箭头 + 圆点指示器 + 右箭头，`.sg-tl-controls`）
- **页码标签**：`第 X / Y 页 · 关键节点`，随滚动实时更新
- **条目结构**：折叠态显示 `t-img` + `t-info`（time + title + desc + hint）；展开态追加 `t-story`（label + 长文 + 收起按钮）
- **展开动画**：`flex-basis` 过渡 + 故事区 `opacity` 淡入；展开时关闭 scroll-snap，定位完成后再恢复
- **互斥**：同一时间仅一个条目展开，展开新条目自动收起旧条目
- **收起**：点击收起按钮 / ESC / 点击其他条目

### 4.4 作品视图（Works）- 3D 中心聚焦轮播

- **5 档位 3D 透视**（`perspective: 900px`）：

| 档位 | 类名 | PC 尺寸 | 变换 | 透明度 |
|---|---|---|---|---|
| 中心 | `.is-center` | 280×280 | `scale(1) translateZ(50px)` | 1.0 |
| 左右近 | `.is-prev-side` / `.is-next-side` | 132×132 | `scale(.82) translateX(±180px) translateZ(-20px)` | 0.5 |
| 左右远 | `.is-prev-far` / `.is-next-far` | 100×100 | `scale(.68) translateX(±312px) translateZ(-45px)` | 0.28 |

- **自动播放**：3.5 秒/个循环，进入作品 Tab 启动；离开 Tab / 鼠标悬停 / 打开故事面板时停止
- **点击中心卡**：弹出创作背景故事面板
- **点击侧边卡**：切换到该卡为中心
- **故事面板**：覆盖在作品视图上方，左侧封面 + 右侧（年份 + 标题 + 分隔线 + "创作背景"标签 + 正文）；移动端纵向堆叠
- **关闭**：X 按钮 / ESC / 点击面板背景

### 4.5 Modal 体系

| Modal | 触发 | 内容 |
|---|---|---|
| 资料 Modal | "其它"Tab | 2 列 fact-grid，含词条类型/经纪机构/出道日期/成员等 |
| 成员详情 Modal | 小屏点击成员 | 头像信息头 + 关系列表 |

- `role="dialog"` + `aria-modal="true"` + `aria-labelledby`
- X 圆形关闭按钮（`.sg-modal-x-btn`）
- ESC 键关闭
- 点击遮罩关闭（点击内容区不关闭）

## 八、A11y 规范

### 8.1 ARIA 角色

| 区域 | role | 关键属性 |
|---|---|---|
| 画框 | `region` | `aria-label` |
| Tab 栏 | `tablist` | `aria-label` |
| Tab | `tab` | `aria-selected` / `aria-controls` |
| 面板 | `tabpanel` | `aria-labelledby` / `hidden` |
| 详情面板 | `aside` | `aria-live="polite"` |
| 成员卡 | `button` | `aria-pressed`（选中态） |
| Modal | `dialog` | `aria-modal="true"` / `aria-labelledby` |

### 8.2 键盘交互

- **Tab**：在 Tab 栏 / 成员卡 / 箭头 / 圆点 / Modal 内自然 tab 流动
- **Enter / Space**：激活按钮（Tab 切换、成员选中、箭头翻页、圆点跳转）
- **ESC**：关闭 Modal / 故事面板 / 收起展开的时间线条目

### 8.3 图片处理

- 所有 `<img>` 必须有 `alt`（成员名 / 节点标题 / 作品名）
- 装饰性图片（如头像 fallback）使用 `aria-hidden="true"`
- `loading="lazy"` 用于时间线/作品等非首屏图片

## 九、零依赖原则

- **纯原生 JS**：ES5+ 语法，兼容现代浏览器，无 polyfill 需求
- **纯原生 CSS**：Custom Properties + Grid + Flexbox + scroll-snap + transform 3D
- **无构建步骤**：直接 `<link>` + `<script>` 引入即可
- **无第三方库**：不依赖 jQuery / React / Vue / 任何 npm 包
- **JS 中不含案例数据**：`DEFAULTS` 仅提供占位文案与结构骨架，真实数据由调用方传入

---

## 十、数据分离原则

组件库严格遵循"渲染逻辑与案例数据分离"：

| 文件 | 内容 | 职责 |
|---|---|---|
| `src/star-group.js` | 渲染引擎 + `DEFAULTS` 占位 | 可复用逻辑，不含任何案例数据 |
| `examples/blackpink.html` | BLACKPINK 案例数据 | 演示数据契约用法 |
| `examples/template.html` | 占位数据 + 注释 | 空白复用模板 |

> 生产新卡片时，仅需复制 `template.html` 并替换 options 中的数据，无需修改 `star-group.js`。
